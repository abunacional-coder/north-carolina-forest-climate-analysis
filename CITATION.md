# Data sources

This project uses the following public datasets and services:

- [NOAA U.S. Climate Normals](https://www.ncei.noaa.gov/products/land-based-station/us-climate-normals) for the 1991–2020 climate comparison.
- Reference station tables for [Brevard](https://climate-charts.com/usa-stations/nc/usc00311055.html), [Raleigh State University](https://climate-charts.com/usa-stations/nc/usc00317079.html), and [Lumberton](https://climate-charts.com/usa-stations/nc/usc00315177.html).
- [NASA/ORNL Daymet](https://daymet.ornl.gov/) for daily gridded temperature and precipitation estimates at the three forest locations.
- [National Weather Service API](https://www.weather.gov/documentation/services-web-api) for short-term weather forecasts.

The results combine historical station averages, Daymet estimates, and National Weather Service forecast information. The datasets and analysis methods are described in the main [README](README.md).
