# Data attribution and project scope

This repository is an educational Python analysis rather than a peer-reviewed climate data product.

**Source data**
- NOAA U.S. Climate Normals: https://www.ncei.noaa.gov/products/land-based-station/us-climate-normals
- Source station tables: https://climate-charts.com/usa-stations/nc/usc00311055.html, https://climate-charts.com/usa-stations/nc/usc00317079.html, and https://climate-charts.com/usa-stations/nc/usc00315177.html
- NASA/ORNL Daymet: https://daymet.ornl.gov/
- U.S. National Weather Service forecast API: https://www.weather.gov/documentation/services-web-api

Generated outputs inherit these data provenance requirements. Daymet is a gridded estimate; the NWS periods are forecasts, not observations. The Python workflow was prepared with AI assistance; the applicant executed and inspected the results.
